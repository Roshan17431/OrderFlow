# Phase 8 quality gate

Phase 8 is releasable only after the commands below succeed on Java 21. A failed or skipped command is not a pass. Testcontainers tests require Docker.

## Required commands

```bash
./mvnw --version
./mvnw clean verify
docker compose config --quiet
docker compose -f docker-compose.yml -f docker-compose.production-like.yml config --quiet
./scripts/security-scan.sh
./scripts/verify-log-redaction.sh
./scripts/validate-monitoring.sh
./scripts/validate-production-config.sh
```

The Maven reactor covers unit, integration, Kafka, concurrency, scheduler, security, contract, failure-path, Flyway-from-empty, and Hibernate-validation tests. Contract tests live beside their consumers and in `platform-contracts` and `event-contracts`. The optional dependency database scan is:

```bash
./mvnw verify -Psecurity-scan
```

It downloads external vulnerability data and must be reported as unverified if that download is unavailable. An aggregate CycloneDX JSON SBOM is generated by `package`/`verify` under `target/sbom/` and must not be committed.

With Docker available, rebuild and test the real topology:

```bash
./scripts/clean-environment.sh
./scripts/dev-up.sh
docker compose --profile observability up -d
./scripts/smoke-test.sh
./scripts/full-system-smoke-test.sh
./scripts/performance-smoke.sh
docker compose ps
```

## HTTP and security policy

The gateway accepts at most 1 MiB per request by default (`APP_HTTP_MAX_REQUEST_SIZE`). Endpoint DTO constraints impose smaller semantic limits on descriptions, addresses, credentials, and refunds. Oversized requests return a sanitized `413` `ApiError`. Collection endpoints have bounded defaults and maximum sizes; sort values are allowlisted by their owning service.

Gateway rate policies are Redis-backed and independently configurable for login, registration, refresh, order creation, payment confirmation, and webhooks. High-risk requests fail closed when limiter state cannot be checked. CORS allows only configured origins, required methods and headers, and never combines wildcard origins with credentials. Production enables HSTS, secure HttpOnly refresh cookies, external RSA keys, and disables simulators.

## Health policy

Liveness is process-only (`livenessState,ping`) and does not fail for a temporary dependency outage. Readiness includes the critical stores used by that service: PostgreSQL for database owners, Redis for authentication/cart/gateway state, and Kafka for asynchronous services. Only `health`, `info`, and `prometheus` are exposed in the production-like topology. `/actuator/info` exposes application name, version/build metadata, and Java version, never environment properties.

## Evidence retention

CI uploads Surefire/Failsafe reports, contract reports, the SBOM, and dependency-check reports. It must never upload `.env` files, tokens, keys, Docker volumes, or database data. Record the exact commands, pass/fail/skipped totals, containers started, smoke matrix, and every environmental limitation in the completion report.
