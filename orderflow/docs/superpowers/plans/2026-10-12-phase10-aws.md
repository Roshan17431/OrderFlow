**Architecture:** Ubuntu 24.04 EC2 with encrypted persistent EBS, SSM-only administration, immutable ECR images and private Compose services behind Caddy. Same-origin HTTPS, persistent keys, scoped instance secrets and GitHub OIDC. This is a single-server demo, without HA or real payments.

## Global Constraints

- Git root is the parent of Maven/Compose root `orderflow/`; frontend `orderflow/frontend/`.
- Preserve `.vscode/`, databases, volumes, Git history and unrelated containers.
- No AWS apply/destroy, registry publication, production deploy or live DNS changes without explicit authorization.
- Only Caddy publishes 80/443; other services stay private. HTTPS cookies, CSRF, JWT revocation and ownership remain enforced.
- Cloud demo explicitly enables simulators; true production fails closed without supported real providers.
- No secret values in Git, manifests, logs, image layers, Terraform state definitions or public browser configuration.
- All polling/timeouts bounded; schema compatibility and backup required before deployment/rollback.

## Review Focus

- Incorrect AWS account/region/environment must stop before any operation.
- Forwarding header spoofing must not alter trusted rate-limit identity.
- Release failure must preserve the last healthy metadata and never restore business data automatically.
- Persistent key files must remain readable by the non-root auth container and stable across restart.
- Merged Compose must clear local ports/builds/credential defaults, not merely hide them in a separate override.

## Shared Interfaces

- Cloud runtime: `docker compose --env-file <runtime.env> -f docker-compose.yml -f docker-compose.cloud.yml`.
- Cloud variables: `ORDERFLOW_ENVIRONMENT=cloud-demo`, `AWS_ACCOUNT_ID`, `AWS_REGION`, `DOMAIN_NAME`, `RELEASE_VERSION`, `ECR_REGISTRY`, image keys `IMAGE_<SERVICE_NAME_UPPER_UNDERSCORE>` with digest-pinned URIs.
- Host layout: `/opt/orderflow/{releases,config,data,backups}`. Runtime secrets in protected `config/runtime.env`; persistent PEMs `config/jwt-private.pem` and `config/jwt-public.pem`; host parent directory mode 0700. Secret files readable only through intended container mounts.
- Release manifest schema: `schemaVersion`, `releaseVersion`, `gitSha`, `builtAt`, `platform`, `awsAccountId`, `awsRegion`, `environment`, `images` (12 service names, each `uri` and `digest`), `migrationCompatibility` (explicit backward-compatible flag and migration file hashes).
- SSM parameters under `/<project>/<environment>/runtime/`; values provisioned by operator outside Terraform.
- Terraform defaults propose `us-east-1`, `t3.xlarge` (16 GiB evaluation), configurable architecture and volumes; no claim that account/domain is configured.
